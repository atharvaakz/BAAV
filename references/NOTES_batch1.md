## Common structure the professor has seen
1. Industry overview (global -> India, size, CAGR, trends, challenges)
2. Strategy frameworks: Porter's 5 Forces, BCG matrix (by SBU), SPACE, PESTEL, SWOT,
   Blind-spot analysis, Consumer segmentation
3. Ratio analysis, 5 yrs (FY21-FY25): liquidity, solvency, turnover, profitability;
   each ratio = formula -> chart -> observations -> suggestions -> limitations
4. DuPont (3-step ROE, ROA = margin x turnover), sheet per company
5. Beta: 60 monthly returns vs Nifty 50, SLOPE and COVAR/VAR cross-check, alpha, R2;
   Blume adjustment (0.67 raw + 0.33); unlever on book D/E, relever on market D/E (Hamada)
6. WACC: Rf 6.8% (10y G-Sec), ERP 7% (Damodaran), tax 25%; Kd via Damodaran synthetic
   rating (ICR -> spread) + India country spread 2.18%; market-value weights
7. DCF: FCFF two-stage, tapered 5-yr growth, Gordon TV with g = 7%; EV -> equity -> per share vs CMP
8. Relative valuation: EV/EBITDA, P/E (+ 5-yr avg), final verdict table (DCF vs market vs multiples)
9. References

## Weak spots in those projects (where we can do visibly more work)
- DCF base FCFF = NOPAT (assumes reinvestment = 0) yet growth 9-20% -> internally inconsistent
  (growth needs reinvestment: g = reinvestment rate x ROIC). NHPC value Rs35 vs CMP Rs78 left unexplained.
- Inconsistencies: JSW shares 1,742 vs 1,751 Mn; WACC note 10.40% vs report 10.15%;
  gross margin printed as 100%; days payable blank.
- Only 3-step DuPont; no 5-step, no ROE-change attribution, no sensitivity tables, no scenario.
- No sensitivity of value to WACC/g, no football-field chart.

## Real-estate adaptation (DLF, Godrej Properties, Phoenix Mills)
- Ind AS 115 (revenue on completion) makes P&L lumpy -> use pre-sales / collections as operating KPI.
- Inventory dominates assets -> asset turnover is low; turnover/CCC need RE-specific reading.
- Valuation: NAV / SOTP is standard for developers (DLF, Godrej); Phoenix Mills = annuity mall rentals
  (cap-rate / EV-EBITDA on rental EBITDA). Run FCFF DCF too (course requirement) and reconcile.
- DLF has DCCDL rental JV (equity-accounted) -> SOTP: residential + share of DCCDL.
