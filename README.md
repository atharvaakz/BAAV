# BAV Project — Business Analysis & Valuation

Multi-company valuation: advanced DuPont decomposition, DCF, comparables, Excel models.

```
data/raw         downloaded filings & prices (not hand-edited)
data/processed   cleaned financial statements
models/excel     Excel valuation models
notebooks        exploratory analysis
src/bav          reusable Python (dupont, dcf, data loaders)
scripts          CLI entry points
reports          outputs (charts, tables, PDFs)
```

Setup: `pip install -r requirements.txt`
